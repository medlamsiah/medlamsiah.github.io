# Portfolio de Mohamed Lamsiah

Portfolio professionnel construit avec Next.js, React et TypeScript.

## Développement local

```bash
npm install
npm run dev
```

Copier `.env.example` vers `.env.local` et renseigner les variables pour activer l'espace d'administration et le stockage dynamique du CV.

## Commandes de contrôle

```bash
npm run lint
npm run typecheck
npm run build
```
